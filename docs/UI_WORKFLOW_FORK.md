# VoiceBankGen 工作流界面

此公开源码采用 `codex/ui-workflow` 分支的工作流界面，分析、选音、oto、CV/CVVC 共用基础音、后台任务及同步服务均包含在源码中。

## 启动

按 [README](../README.md) 安装依赖后运行 `voicebankgen`。安装器源码和构建步骤见 [安装器构建](BUILDING.md)；公开仓库不附带 EXE、模型、运行环境或示例工程。

打开已有工程后可以继续编辑，修改仍会写入该工程。请勿同时启动两个程序编辑同一个工程。

## 深色 / 浅色主题

默认采用深色界面。可从 **工具 → 界面主题 → 深色（默认） / 浅色** 随时切换，立即生效并记住选择，下次启动沿用；启动进度窗口也跟随选择。菜单、候选列表、输入框、设置及拼接窗口使用同一主题，波形和拼接时间线保留专用深色画布。系统原生文件选择窗口遵循 Windows 自身设置。

切换主题不改变工程、选音、oto 或同步状态，不需要重新分析或同步音源。

## 推荐操作顺序

1. 首页新建或打开工程。在顶部选择需要编辑的音源版本。
2. **01 素材与切分**：添加录音或拖入文件，确认来源语言、计算设备和对齐工具，点击「开始自动切片」。列表区分已导入和待处理素材，重复添加会去重；「移出待处理列表」保留磁盘文件。已有候选的工程打开后直接进入校对页。
3. **02 校对与选音**：从左到右依次是音节、候选和波形。点击音节，再点击候选试听；点击「使用这个音」才改变正式选音。空格从头播放当前候选的 UTAU 使用区间，没有 oto 则播放完整切片。试听按钮播放中再次点击可停止。
4. 在波形中拖动标线，或输入下方的毫秒数。修改自动暂存；一次完整拖动记录一步，Ctrl+Z / Ctrl+Shift+Z 撤销 / 重做，最多 8 步。高级 oto 数值和重置操作在「标线操作」内。
5. **03 同步与导出**：底部「同步修改」统一生成音源并更新已绑定安装。首次使用可点「安装到目录」；需要分享音源时先同步最新编辑，再从「导出」菜单选择 ZIP。导出切片仍可选择各音最佳 X 个或全部候选。

三个工作区随时可切换，无需按顺序解锁。后台任务显示进度、耗时、取消和详情；任务中相关操作会禁用。安装目录发生外部冲突时，该目录被选中后才显示处理按钮。

首页的最近工程单击后显示蓝色边框和底色，焦点移开后仍保留选中状态；双击打开工程。

列表采用紧凑行距。拼接工作台底部「保存目标」旁可输入音名、罗马音或拼音筛选目标下拉框；选定发音后点击「保存到候选」。搜索框右侧可清空搜索，无匹配时不能保存到其他音名。

搜索在停止输入约 250 毫秒后执行，按 Enter 可立即执行。主界面直接筛选已加载音节列表；仍匹配当前音节时保留波形和试听。保存拼接结果时会立即确认最新搜索条件，防止快速输入后保存到旧目标。

## 操作入口对照

| 功能 | 新位置 |
| --- | --- |
| 新增 CV/CVVC、音源设置 | 右上「版本设置」或顶部「音源」菜单 |
| 批量优化 VC / VV | 顶部「音源」菜单 |
| 强制标注 oto | 顶部「校对」菜单 |
| 新增自定义音 | 校对页左侧「新增音」 |
| 导入音、编号备选、接受 / 排除候选、单独导出 | 候选列表下方「候选操作」；部分操作也可右键使用 |
| 暂停 / 继续、正式音对比、处理后试听、短音 / 长音渲染 | 波形下方「对比与渲染」 |
| 解锁、初始化、恢复自动、直接编辑 oto | 波形上方「标线操作」 |
| 拼接工作台、可选补音、跨语种拼接 | 顶部「工具」菜单 |
| 模型设置、模型 / 环境下载 | 顶部「工具」菜单 |
| 安装、ZIP、切片导出、生成目录 | 「同步与导出」工作区 |
| 按钮用途说明、任务日志 | 顶部「帮助」菜单；控件悬停也有说明 |

从起点播放、试听备选入口合并为一个试听按钮；暂停 / 继续保留在「对比与渲染」菜单。高级 oto 数字框也可按空格试听。切换离开校对页后，迟到的缓存结果不会自动播放。「暂缓同步」不再占用按钮：保留草稿并继续编辑即可。

## 开发

布局在 `src/utau_forge/workflow_ui.py`，业务回调仍在 `app.py`，不复制分析或同步实现。新增模块列入源码发布白名单。

主程序代码位于 `src/utau_forge/`，自动化测试代码位于 `tests/`。测试所需短合成音频在临时目录生成，真实录音、测试工程和本机验证报告不随源码分发。界面检查不能替代 OpenUtau 中的歌唱听感校对。
