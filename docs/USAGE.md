# 从源码使用 VoiceBankGen

> 当前 UI fork 的三个工作区与操作入口见 [工作流界面手册](UI_WORKFLOW_FORK.md)。模型相关设置已收进顶部「工具」菜单。

## 准备

先按 [README](../README.md) 安装 Python 3.11、应用依赖、TIFA 推理依赖、固定版本的 TIFA 源码和 FFmpeg。此仓库不包含模型、第三方运行环境或可直接双击的 EXE。

运行 `voicebankgen` 打开桌面程序。到 **工具 → 模型 / 环境下载** 下载 TIFA 模型、UniDic 和 Whisper small；模型受各自许可约束，详见 [第三方说明](../THIRD_PARTY_NOTICES.md)。源码模式的下载面板主要准备模型；TIFA Python 依赖和 FFmpeg 按 README 单独安装。保存于本机的下载清单只有 URL、大小和哈希，不是模型本体。

下载源可选官方或镜像；GitHub 和 Hugging Face 镜像分别填写，HTTP / HTTPS 代理可填 `http://127.0.0.1:7890` 等本机代理地址。使用自己的有效端口；镜像和代理不改变文件哈希检查。源码依赖的 pip 下载网络需要单独配置。安装器源码和打包步骤见 [BUILDING](BUILDING.md)。

若已有模型，打开 **工具 → 模型设置**，选择对应目录并保存；也可以使用自动识别。模型放在软件资源目录，录音工程可放在另外的目录。

## 第一个工程

1. 新建工程，选择实际录音的来源语言（日语或普通话），选择要制作的目标语言与 CV / CVVC 版本。
2. 导入自己拥有使用权的单人录音。先用短片段验证效果，再处理长录音。多人混杂或背景音乐会影响识别和切分。
3. 点击自动切分 / 分析。流程包括 VAD 分段、Whisper 转写与 TIFA 对齐；确认识别文本，必要时修正后重试。
4. 左侧选择发音，右侧选择候选。**点击候选用于试听，点击“使用这个音”才确定正式选音**。
5. 按空格播放当前候选的实际使用区间；使用 A / B 比较正式音与候选。
6. 拖动五条标线或输入毫秒数，校对使用起点、重叠、对拍点、固定区结束、使用终点。
7. 编辑先保存在工程草稿中。完成后点击 **同步修改**，统一应用到生成 / 已绑定的音源。

## 编辑与拼接

### 后台任务状态

同步、批量优化等操作开始后，下方任务行会分别显示启动后台、初始化组件、实际处理和批量暂存阶段，并持续刷新已用时间与最近回报时间。首次启动后台程序可能较慢，启动在独立线程执行；窗口仍能重绘、查看任务详情和请求取消。超过 10 秒没有进度回报时，会提示“后台暂未回报”，不会当作已完成。

取消显示“正在取消”，直到后台结束后恢复按钮；已保存或已提交的修改保留。批量优化的原子暂存阶段会短暂锁定编辑，进度继续显示；写入结束后恢复编辑，可整批撤销。此阶段不强制中断数据库事务。

- 一次完整拖动记录一步撤销；主编辑器最多保留 8 步历史。`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。工作台有独立的 8 步历史。
- 默认保留原音高。需要时在音源设置启用标准音高处理，处理后仍需试听。
- 新增编号备选可以保留同一发音的多种声音，如 `a_1`、`a_2`。日语 oto 默认使用平假名，亦可切换罗马音或片假名；音频文件名使用罗马音 / 拼音。
- **新增音**创建自定义标签；**导入音**将外部音频加入选中发音的候选。
- 拼接工作台可使用已对齐的整音、辅音和元音，移动、裁剪、调整重叠与淡化。在红色光标处按 `S` 切分；可保存为候选或单独导出 WAV。
- 自动补缺音和跨语种拼接是可选的近似方案；需要人工确认发音、连接和长音质量。呼吸音可按对齐标签选择加入。
- 导出切片时以保存对话框选择的位置为准。工程原始切片、生成音源和导出 ZIP 是不同产物。

## 在 OpenUtau 使用

### CVVC 衔接优化

**音源 → 批量优化 VC / VV 音素**：为当前 CVVC 版本的 VC、VV 和配套 CV 设置正重叠，改善连接处交叉淡化。默认 30 ms，可输入 5–100 ms；按现有前置区自动缩短，不移动对拍点，不重新处理 WAV。VC/VV 参数独立保存，基础 CV 调整在关联版本共用。已锁定重叠或没有可用前置区的候选跳过并显示数量。整批可一步撤销，校对后点 **同步修改**，再在 OpenUtau 重新载入音源。乐谱中已有的手动包络 / 先行音覆盖需在 OpenUtau 中自行清除后观察默认衔接。

**CV 和对应 CVVC 共用基础音节**。两边的选音、oto 和锁定、编号备选、自定义音、呼吸音、音高及导出设置双向生效；VC/VV 的选音和 oto 单独保存，名称与安装位置各自保留。点击 **同步修改** 一并更新已绑定的关联版本；外部冲突保留并提示。

现有工程首次打开以唯一匹配的 **CV 现有调整为准**，旧 CVVC 基础记录保留供恢复，不覆盖 CV；VC/VV 调整保持。有多个 CV 时，在 **音源设置 → 共用基础 CV** 选择；仅有 CVVC 时由现有基础音节建立 CV。

**新增 CV/CVVC 版本**先暂存当前标线。新增 CVVC 关联对应 CV，从已有对齐提取缺少的 VC/VV，仅为 VC/VV 设置初始衔接，保留基础 CV 的现有调整；无需再加载模型或重跑转写。需要进一步处理两侧衔接时使用 **批量优化 VC / VV 音素**。没有对齐数据时会提示先自动切片；恢复工程也可优化已有连接音。

安装到一个独立音源目录，或导出后放入 OpenUtau 的 Singers 目录。重新载入音源后选择匹配的 phonemizer；日语 CVVC 的平假名别名可配合 JA CVVC（legacy），罗马音、自定义和编号别名要使用支持这些别名的配置。

试听短音、长音、变调和连续连接；文件齐全或覆盖率达到目标不等于音质已经验收。OpenUtau 与 resampler 需要另行安装，本仓库不分发这些程序或任何第三方声库。

## 限制

主要开发平台为 Windows x64，其他平台未全面验证。源码安装不会获得本机实验数据或已验证声库。ASR 可能出错，官方前端可能跳过不支持的文字；中文 / 跨语种歌唱效果需自行验收。MFA 仅保留可选旧接口，不是默认流程，也不要求安装其环境。


## 歌声与歌词导入

素材页选择「导入歌声及歌词」，依次选择干声与 UTF-8 逐行 LRC；在波形窗口检查偏移、边界与文本，点击「确认并开始对齐」后自动进入 TIFA。失败查看素材页错误并重试。同一工程可以混合语音与歌声，素材列表标记来源；已导入素材可右键删除，删除前弹出确认。完整步骤与格式限制见 [README](../README.md)。
