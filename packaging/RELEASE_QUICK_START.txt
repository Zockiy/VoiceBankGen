VoiceBankGen 使用说明

离线完整版包含主程序、CPU 推理环境、语音识别与对齐所需模型。
安装时选择有足够空间的目录，完成后启动 VoiceBankGen。
无需另外安装 Python、Conda 或 MFA；默认使用 CPU。

安装时可勾选“安装 NVIDIA GPU 加速组件”，为转写与 TIFA 对齐安装 GPU 配套库。
需要兼容 CUDA 12.4 的 NVIDIA 显卡及驱动；安装器不会安装或更新显卡驱动，
也不会安装完整 CUDA Toolkit。GPU 组件额外约 4 GiB，另有压缩安装缓存。
未勾选时跳过 GPU 环境和缓存，不影响 CPU 使用；之后可重开安装器补装。
安装 GPU 组件后，在“素材与切分”的计算设备中选择“自动”或“NVIDIA GPU”。
选择“CPU”始终使用 CPU；GPU 组件与 CPU 环境可以共存。

1. 新建工程，选择录音来源语言和音源目标语言，导入单人语音。
2. 在“素材与切分”页选择 TIFA，开始自动切片并核对识别文本。
3. 在“校对与选音”页选择发音和候选。空格试听，“使用这个音”确定选用。
4. 拖动标线或编辑 oto 数值；需要时从“工具”打开拼接工作台。
5. 编辑先暂存。点击下方“同步修改”统一应用，再安装或导出音源。
6. 在 OpenUtau 重新载入音源，选择适合的 phonemizer 并试听。

默认保留原音高。日语 oto 默认使用平假名，音频文件名使用罗马音。
Ctrl+Z / Ctrl+Shift+Z 撤销 / 重做，最多 8 步；拼接工作台有独立历史。
默认深色界面，“工具 → 界面主题”可切换浅色。
“帮助 → 按钮用途说明”可查看操作说明，控件悬停也有提示。

请使用具有相应授权的录音。自动分析与拼接结果需要人工试听校对。
本软件不附带第三方录音、声库、OpenUtau 或 resampler。
