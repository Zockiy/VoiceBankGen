VoiceBankGen 便携版使用说明

1. 使用 7-Zip 等工具将整个压缩包解压到有足够空间的目录，不要直接在压缩软件中运行。
2. 打开解压后的 VoiceBankGen 文件夹，双击 VoiceBankGen.exe。
3. 保留 _internal、resources、runtime 等目录；不要只移动主程序 EXE。
4. 新建工程，导入单人录音，在“素材与切分”页选择 TIFA 并开始自动切片。
5. 校对识别文本、候选和 oto，点击“使用这个音”确定选用。
6. 编辑先暂存，点击底部“同步修改”后安装或导出音源。

CPU / GPU 选择
GPU 版共用一套支持 CPU / NVIDIA GPU 的运行环境，无需另外安装 Python、Conda、
MFA 或完整 CUDA Toolkit。首次使用也不需要下载模型。
在“素材与切分”的计算设备中选择：
- 自动：优先尝试可用 GPU，不可用时回退 CPU。
- CPU：使用 CPU 计算。
- NVIDIA GPU：明确使用 GPU；不可用时会提示错误，可切回 CPU。
GPU 环境为 PyTorch 2.6.0+cu124，需要兼容 CUDA 12.4 的 NVIDIA 显卡及驱动。
本包不会安装或更新显卡驱动。CPU 回退共用相同依赖，不另附一套 CPU PyTorch。

空格试听当前候选；没有 oto 时播放完整切片。
Ctrl+Z / Ctrl+Shift+Z 撤销 / 重做，最多 8 步；拼接工作台有独立历史。
默认保留原音高；日语 oto 默认使用平假名。
“工具 → 界面主题”可切换深色 / 浅色。
“帮助 → 按钮用途说明”及控件悬停提示提供详细操作说明。

建议将工程保存在软件目录之外。组件损坏时，将原压缩包重新解压到一个新目录，
再打开已有工程；本便携包不额外保存一份体积庞大的安装修复缓存。
请使用有权使用的录音，自动分析与拼接结果仍需人工试听校对。
本包不附带第三方录音、声库、OpenUtau 或 resampler。
